# Hospital Operations Analytics Project

## Project Overview
This project aims to analyze fictional hospital operations data to identify patterns in patient admissions, length of stay, departmental activity, and billing.

## Objectives
- Analyze patient admissions across hospital departments.
- Calculate and compare patient length of stay.
- Examine billing patterns across departments.
- Identify operational trends and opportunities for improvement.
- Develop data-driven recommendations for hospital management.

## Tools
- Microsoft Excel
- SQL
- Power BI (planned)

## Dataset
The project will use synthetic hospital data created for educational and portfolio purposes. No real patient information will be used.

## Methodology
1. Create and organize the dataset.
2. Clean and validate the data.
3. Analyze the data using Excel.
4. Write SQL queries to answer operational questions.
5. Create visualizations and summarize key findings.
6. Develop recommendations for hospital operations.

## Expected Deliverables
- Hospital dataset
- Excel analysis and dashboard
- SQL queries
- Project report with findings and recommendations

## Project Status
In progress — dataset preparation and analysis are the next steps.
